Privacy Policy

Last updated: October 24, 2026

Finance Man Postiz ("the app") is a self-hosted tool run on the owner's own computer. It is used only by its owner to manage the owner's own social media accounts.

What data the app accesses

When the owner connects an account (for example YouTube via Google sign-in), the app receives an access token and basic profile information (channel name, picture, email) so it can upload and schedule videos the owner chooses.

How data is used and stored

  • Data is used only to publish and schedule the owner's own content.
  • Tokens and data are stored only on the owner's computer and are never sold, shared or sent to third parties, other than the platform the content is posted to.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, which stops the app from using the account.
